อัปโหลดทุกไฟล์ในโฟลเดอร์นี้ไปที่ระดับบนสุดของ Repository เดียวกัน (ไม่อัปโหลด ZIP ตรง ๆ)
ไฟล์ index.html เป็นหน้าเว็บหลัก ส่วนรูป โลโก้ manifest และ sw.js จำเป็นสำหรับแสดงผลครบถ้วน
สร้าง Repository ใหม่ > Add file > Upload files > Commit changes
Settings > Pages > Deploy from a branch > main / (root) > Save
เปิดลิงก์ Pages ผ่าน Safari บน iPhone > Share > Add to Home Screen
